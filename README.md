## **PIC处理相关技术路径**
为了实现对video文件的解析，在video playing的同时，使用yolo模型对每一帧数据进行判断，并将目标区域以指定格式，指定文件名格式，保存到指定的文件目录。这期间涉及到的技术实现方案包括yolo的模式识别，opencv使用，格式定义等细节实现。
### **yolo相关的技术方案介绍**
